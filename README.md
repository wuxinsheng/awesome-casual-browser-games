## What makes a game worth including?

Games in this collection should:

- Work directly in a modern web browser
- Have a clear and interesting core mechanic
- Be playable in short sessions
- Offer a free or free-to-start experience
- Link to an identifiable original publisher
- Avoid misleading downloads and intrusive redirects

## About CasualAtlas

[CasualAtlas](https://www.casualatlas.com/) is an independent directory of
casual browser games. It helps players discover worthwhile games, understand
the rules, find useful guides, and visit the original publishers.
